# data-analysis
World Happiness Report
Проект в рамках курса "Python Programming" посвящён анализу данных из датасета с Kaggle "World Happiness Report".
Целью было научиться работать с данными с множеством колоннок и строк, с помощью Python изучить динамику показателей счастья в разных странах, определить ключевые факторы и понять, какие характеристики больше всего коррелируют с уровнем счастья, представить визуализации.
В репозитории находятся CSV-файлы с данными за 2015-2023 годы и сам файл с проектом whrproject2024.ipynb
Для обработки, очистки и визуализации данных использовался Python (pandas, numpy, matplotlib, seaborn, plotly)
Основными шагами были:
- Объединение и очистка данных датасетов
- Изучение распределений и корреляций  
- Построение графиков и визуализации со сравнением стран и временных отрезков
Итогами было:
- У стран с высоким уровнем счастья обычно выше показатели GDP, Social Support и Healthy Life Expectancy.  
- Показатели сильно меняются на 2020 году, где весь мир потряс коронавирус COVID-19
- За последние годы многие развивающиеся страны показывают улучшение ключевых индикаторов.
